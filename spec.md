# PriceTag — Lean Sellable Spec
Name: PriceTag (available, no dominant competitor)
Concept: Snap product barcode/shelf tag → log price/store/date → history graph → drop alert → cheapest nearby (crowd/user)
Sell: $2.99 one-time or $0.99/mo subscription. Consumer-facing.
Lean stack: React Native / Flutter or simple web PWA. SQLite local + optional cloud sync.
Features (MVP):
1. Barcode/photo scan (ZXing / ML Kit)
2. Price + store + date log
3. Price history chart
4. Drop alert (local notification)
5. Basic "nearby" price comparison (user-reported)
Built with Claude Code (core) + Gemini (vision/OCR validation).
